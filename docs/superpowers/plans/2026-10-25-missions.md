# Missioni giornaliere, settimanali, mensili e comuni — piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** sostituire gli obiettivi del giorno con missioni personali (giorno/settimana/mese) su misura per gruppo, missioni comuni per ambito, serie funzionante e badge, con riscatti verificati dal server.

**Architecture:** logica pura in `CarSpot/Services/Game/` (regola-dati `MissionRule` gemella di SQL, periodi, gruppo, repertorio, generatore con seed stabile, tabellone per la UI, serie); stato in `PlayerProfile`; sync dei riscatti/badge/missioni comuni in `SyncService`; UI in `Features/Today/` (selettore a 4 segmenti con pallini numerati). Server: migration 0011 con tabelle e trigger `private.award_mission` che ricalcola il progresso.

**Tech Stack:** SwiftUI iOS 26, Swift 6 strict, SwiftData, Swift Testing, Supabase (Postgres, PL/pgSQL).

**Spec:** `docs/superpowers/specs/2026-10-25-missions-design.md` (valori, tabelle del repertorio, regole di serie e finestre). ADR: `docs/adr/0002-missioni-regole-dati-verificate-dal-server.md`.

## Global Constraints

- Swift 6 strict, **niente** Default Actor Isolation = MainActor: `@MainActor` espliciti; tipi logici `Sendable`, puri, senza SwiftData (tranne l'init da `StoredCard`).
- Commenti in italiano, brevi. Logging con `Logger` di `os`. Test con Swift Testing (`@Test`, `#expect`, `try #require`).
- Testi UI in italiano con `String(localized:)` / `LocalizedStringKey`; **non** toccare `Localizable.xcstrings`.
- Design system: `CSColor`, `CSFont` (mai `.system(size:)` per testo), `CSSpace`, `CSRadius`, `CSSize.minTap`, `Surface(.group)`, `SurfaceDivider`, `StatBar`, `CSPressStyle`. Reduce Motion sempre rispettato. Niente aloni/neon/numeri che rotolano.
- Non toccare: `StoredCard.swift`, `CaptureViewModel.swift`, `MapBackground.swift`, `RootShellView.swift`, `CollectionView.swift`, `CardDetailView.swift`, `SpotCardView.swift`, la parte carte di `SyncService`, `CLAUDE.md`, `tools/`, `project.pbxproj`.
- Niente simulatori, niente commit. Verifica = solo compilazione:
  `xcodebuild -project CarSpot.xcodeproj -scheme CarSpot -configuration Debug -destination 'generic/platform=iOS Simulator' -derivedDataPath <scratchpad>/dd-<nome> build-for-testing 2>&1 | grep -E "error:|TEST BUILD SUCCEEDED|BUILD FAILED"`
  → atteso `** TEST BUILD SUCCEEDED **`. Se fallisce per un file non tuo (altre sessioni lavorano in parallelo) aspetta 1–2 minuti e riprova.
- Normalizzazione testi = gemella di `private.norm` / `CardCopies`: minuscole, spazi ai lati tolti, spazi interni ridotti a uno.
- Calendario delle missioni: `Calendar(identifier: .gregorian)`, `firstWeekday = 2`, `minimumDaysInFirstWeek = 4`, `timeZone = .current`. Chiavi data `yyyy-MM-dd` con `en_US_POSIX` (come `PlayerProfile.dayKey`).

## Review Focus

1. **Periodo a cavallo di un cambio d'ora (DST)**: la settimana del 26 ottobre dura 7 giorni di calendario, non 168 h → `MissionPeriod.end` = `start + 7 giorni` con `Calendar`, test in Task 2.
2. **Carte con anno 0 o area vuota**: non devono contare per `year_from/year_to` né per `count: areas` / `fresh: area` → test in Task 1.
3. **Primo avvio senza carte / ospite**: gruppo Occasionale·Generalista, serie 0 `lost`, nessuna missione comune, generatore che non va in crash con pool di slot ridotti → test in Task 3, 4, 5.
4. **Ritorno dopo giorni di assenza**: la UI deve mostrare le missioni del periodo nuovo e, per i 2 giorni di grazia, gli avanzi da riscattare del periodo precedente; dopo la scadenza spariscono → test in Task 6.
5. **Due foto della stessa auto** dentro una lista bersaglio o "modelli nuovi": contano 1 → test in Task 1.

### Task 2: Periodi e seed stabile

**Files:**
- Create: `CarSpot/Services/Game/MissionPeriod.swift`, `CarSpot/Services/Game/StableRandom.swift`
- Test: `CarSpotTests/MissionPeriodTests.swift`

**Interfaces — Produces:**
```swift
enum MissionPeriodKind: String, Codable, Sendable, CaseIterable { case day, week, month, community }

struct MissionPeriod: Sendable, Hashable {
    let kind: MissionPeriodKind
    let start: Date
    let end: Date                       // esclusiva
    let startKey: String                // "yyyy-MM-dd" nel fuso del calendario
    var claimDeadline: Date             // end + 2 giorni di calendario (salvata in init)
    static func containing(_ date: Date, kind: MissionPeriodKind, calendar: Calendar) -> MissionPeriod   // day/week/month
    func previous(calendar: Calendar) -> MissionPeriod                                                  // day/week/month
    /// Comuni: date incluse "yyyy-MM-dd" → [startsOn 00:00, endsOn+1 00:00). nil se non valide.
    static func community(startsOn: String, endsOn: String, calendar: Calendar) -> MissionPeriod?
    func identity(_ missionId: String) -> String    // "\(kind.rawValue):\(startKey)|\(missionId)"
}
extension Calendar { static var missions: Calendar }   // vedi Global Constraints

/// FNV-1a 64 bit della stringa (utf8) → SplitMix64. Mai `hashValue`.
struct StableRandom: RandomNumberGenerator {
    init(seed: String)
    mutating func next() -> UInt64
}
```
FNV-1a: offset `0xcbf29ce484222325`, prime `0x100000001b3`. SplitMix64: `state &+= 0x9E3779B97F4A7C15; z = state; z = (z ^ (z >> 30)) &* 0xBF58476D1CE4E5B9; z = (z ^ (z >> 27)) &* 0x94D049BB133111EB; return z ^ (z >> 31)`.

- [ ] **Step 1: test** (`MissionPeriodTests`, calendario con `timeZone = Europe/Rome`):
  - `settimanaDaLunedi`: 2026-10-29 (giovedì) → `startKey == "2026-10-26"`, `end` = 2026-11-02 00:00 locale.
  - `settimanaConCambioOra`: 2026-10-25 (domenica, giorno del cambio) → `startKey == "2026-10-19"`, `end` = 2026-10-26 00:00 locale (Calendar, non +168 h).
  - `meseDalPrimo`: 2026-10-25 → `startKey "2026-10-01"`, end 2026-11-01; `previous` → `"2026-09-01"`.
  - `scadenzaDueGiorni`: giorno 2026-10-25 → `claimDeadline` = 2026-10-28 00:00 locale.
  - `comuneDateIncluse`: `community(startsOn: "2026-11-01", endsOn: "2026-11-30")` → end = 2026-12-01 00:00; stringa non valida → nil.
  - `identita`: `"week:2026-10-19|w_makes"`.
  - `seedStabile`: due `StableRandom(seed: "u|week|2026-10-19")` danno le stesse 5 uscite; seed diverso → prima uscita diversa.
